这一版改了什么

格式能力从"单张不透明图片 + 无音轨视频"扩到"透明图片 + 带音轨视频 + 主流格式双向互转"，同时把播放窗口上的技术指标全部删掉。

照片 MTB · 红 M 视频 MTC · 蓝 M
透明怎么存
alpha 作为独立平面跟在头后面（长度 + 熵编码流），RGB 照原有 DCT 流程。透明区（alpha<8）的 RGB 预置 0，避免半透明边缘出现脏色。
音轨怎么存
ffmpeg 把音轨解成 44.1 kHz 立体声 PCM，整段以 WAV 形式塞进 MTC 头部之后的音频段，不重编码，因此没有二次损失。
播放怎么对齐
画面按头里的 fps 定时刷新，音频用系统播放器异步启动。这是粗同步：不做逐帧时间戳对齐，长片会漂。

尺寸阶梯：从 360P 到 4 倍 4K

同一张 2048×2048 壁纸重新采样到各档尺寸再编码（q80、4:2:0）。"4 倍 4K"按 7680×4320 理解，另用 1080p 源放大单独实测。

柱是 MTC 体积（KB），线是 PSNR（dB）。放大档的 PSNR 反而更高，因为放大让画面变平滑、同一步长更容易贴合——这不是"画质更好"，跨尺寸比 PSNR 没有意义。

视频：四段 MP4 转 MTC，音轨全在

每段抽 12 帧（12 fps，前 1 秒），分辨率按 720p 预设等比缩放，音轨同时抽出 1 秒 PCM 嵌入。四段全部转换成功，音轨一段没丢。

堆叠柱：下半是画面码流，上半是音频。音频占比 24%–59%——因为 PCM 不压缩，1 秒就是 172 KB，比 12 帧画面还占地方。

PNG 动图与透明

APNG 转 MTC：8 帧一帧不少

用壁纸合成了一个 8 帧 APNG（320×180，每帧 90 ms），Pillow 读出的 n_frames 为 8，编码成 MTC 后解码仍是 8 帧，28465 字节，编码 0.35 s。

需要说明的取舍：MTC 是视频容器，帧率统一，APNG 每帧的独立时长与透明通道不会带过去。要保住逐帧时长，就得给容器加按帧时间戳，这一版没做。

透明往返：alpha 逐位相等

把一张 1080×1080 壁纸做成圆形渐隐的 RGBA，编码成 MTB 再导回 PNG，重新读入后 alpha 通道与原图完全逐位相等（RGB 在 alpha≥8 处也逐位相等）。

体积：RGBA 1080×1080 → MTB 128.7 KB → PNG 625.9 KB。

界面：不再显示任何指标

按"跟 PNG / MP4 差不多"的要求，窗口里删掉了一整条状态栏。图片打开就是一张图，视频打开就是自己在放。

代价与还没做的

项实测代价说明
超大图耗时17–82 s / 张8K 两张实测差了 5 倍；纯 Python 逐符号算术编码，暂时没有多线程或分块并行
视频只抽前 1 秒12 帧 / 段默认 --max-frames 24，测试为了控制时长跑了 12 帧；不是完整片长
音频不压缩172 KB / 秒PCM 原样存，占容器 24%–59%；要更省得把音频改存 AAC/Opus 并标记编码类型
音画粗同步会漂音频靠系统播放器异步启动，没有逐帧 PTS；短片可用，长片必然对不上
MTC 无 alpha—视频容器仍是纯 RGB；带透明的动图转 MTC 会丢透明（转 MTB 可保住单帧透明）
依赖 ffmpeg外部程序视频读写必须调 ffmpeg，本机是 D:\ffmpeg-…-essentials_build\bin\ffmpeg.exe；没装则图片功能照常、视频功能报错提示
非 Windows 无音频静音播放音频播放走 winsound，Linux / macOS 上画面能放、声音先不响

命令速查

# 图片：PNG/JPG/动图 -> MTB，顺带指定尺寸和透明度
python -m mtcodec convert 壁纸.png 壁纸.mtb --size 1080p -q 80
python -m mtcodec convert 透明图.png 透明图.mtb -q 85

# 视频：MP4（带声音）-> MTC
python -m mtcodec convert 片子.mp4 片子.mtc --size 720p --fps 12 --max-frames 24

# 反向：回到主流格式
python -m mtcodec export 壁纸.mtb 壁纸.jpg
python -m mtcodec export 片子.mtc 片子.mp4        # 含音轨
python -m mtcodec export 片子.mtc 帧目录           # 导出 PNG 序列 + audio.wav

# 看/播（窗口里不再显示帧率等指标）
python -m mtcodec open 片子.mtc

# 头部信息仍然可查
python -m mtcodec info 壁纸.mtb
python -m mtcodec video-info 片子.mtc
